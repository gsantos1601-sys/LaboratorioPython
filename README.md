## 📖 Sobre el proyecto

Este repositorio reúne mis prácticas de laboratorio de Python. Cada práctica es un **cuaderno independiente**, organizado por sección y capítulo, con su descripción, el código comentado, la explicación de lo importante y un ejemplo de salida.

El objetivo es llevar un registro ordenado de mi aprendizaje y tener un portafolio claro de lo que voy practicando.

## ▶️ Cómo usar los cuadernos

### Opción 1: en Google Colab (recomendada)

1. Pulsa el botón **Abrir en Colab** de la práctica que quieras ver.
2. Ejecuta las celdas en orden con `Shift + Enter`.

No necesitas instalar nada.

### Opción 2: en tu computadora

```bash
# Clona el repositorio
git clone https://github.com/gsantos1601-sys/python-laboratory.git

# Entra a la carpeta del proyecto
cd python-laboratory

# Instala Jupyter (solo la primera vez)
pip install notebook

# Abre Jupyter y elige el cuaderno que quieras
jupyter notebook
```

## 🧩 Formato de cada práctica
